# 카톡 도우미 (안드로이드)

자판 치기가 힘든 분을 위한 앱입니다. 카톡 대화방에 뜨는 **노란 💬 버튼**을 누르고 편하게 말하면, **정중한 말로 바꿔서** 보내 줍니다.

> "야 이거 토요일에 하자고 해" → "이 일은 토요일에 하도록 하겠습니다."

## 쓰는 법 — 버튼 한 번
1. 카톡 대화방을 엽니다. 오른쪽에 노란 **💬 도우미** 버튼이 떠 있습니다. 손가락으로 끌어서 옮길 수 있습니다.
2. 버튼을 **한 번** 누르고 편하게 말한 뒤, 끝에 **"보내 줘"** 또는 **"끝"**이라고 합니다.
   예) "이거 토요일에 하자고 보내 줘" / "내일은 못 간다고 해 끝"
   - 중간에 쉬어도 끊기지 않고 계속 듣습니다. 신호 말을 잊어도 6초쯤 조용하면 거기까지 한 말로 진행합니다.
   - 신호로 알아듣는 말: 보내, 보내 줘, 보내 주세요, 전송, 끝, 끝내, 이상
3. 자동으로 정중하게 다듬어 크게 보여 주고, **3초 뒤에 카톡으로 보냅니다.**
   - 잘못 알아들었으면 3초 안에 **✋ 취소**를 누르세요. 문장을 고치거나 다시 말할 수 있습니다.
   - 확인하고 보내고 싶으면 앱 설정에서 **"말이 끝나면 확인 없이 바로 보내기"**를 끄세요.

## 설치 (부모님 휴대폰에도 같은 방법)
설치와 설정은 처음 한 번만, 자녀분이 해 드리는 것을 권합니다.

1. **앱 파일 받기**: GitHub 저장소 → **Actions** → "카톡 도우미 앱 빌드" → 맨 위 초록색 ✅ 실행 → 아래 **Artifacts**의 `talk-helper-apk`를 받습니다. zip을 풀면 `app-debug.apk`가 나옵니다.
2. **휴대폰에 설치**: apk 파일을 휴대폰으로 보내(카톡 나에게 보내기, 메일 등) 누르면 설치됩니다. "출처를 알 수 없는 앱" 허용을 물으면 허용합니다.
3. **카톡 도우미 앱을 열고** 화면 순서대로 합니다.
   1. **카톡 위 버튼 켜기**: 설정 → 접근성 → 설치된 앱 → 카톡 도우미 → 켜기
      - 회색으로 막혀 있으면: 앱 화면의 **앱 정보 열기** → 오른쪽 위 ⋮ → **제한된 설정 허용** → 다시 켜기. 스토어 밖에서 설치한 앱이라 안드로이드가 한 번 더 확인하는 절차입니다.
   2. **마이크 허용**
   3. **Claude API 키** 넣기
   4. **내 이름**, **나는 어떤 사람인가요?** 넣기 (예: 신부님은 "본당 주임신부", 부모님은 "70대 어머니" 등. 말투에 반영됩니다)
   5. **저장** → **여기서 시험해 보기**로 확인
4. 부모님 휴대폰에도 **같은 API 키**를 넣으면 됩니다. 요금은 그 키 계정 한 곳으로 청구됩니다.

## 보내기가 안 될 때
카톡 앱 업데이트로 화면 구조가 바뀌면 자동 입력이 안 될 수 있습니다. 그때는 문장을 **복사**해 두고 알려 드립니다. 카톡 입력창을 길게 눌러 **붙여넣기** 하면 됩니다.
전송까지 자동으로 하지 않으려면 설정의 **"전송 버튼까지 누르기"**를 끕니다. 그러면 입력창에 넣기만 하고, 전송은 직접 누릅니다.

## 개인정보와 요금
- 버튼을 눌러 다듬을 때만 **말한 내용**과 **그 순간 카톡 화면에 보이던 글**(무엇에 대한 답인지 알기 위해)이 Anthropic(Claude)으로 전송됩니다. 그 외에는 아무것도 보내지 않고 저장하지도 않습니다.
- 접근성 기능은 카카오톡 화면만 읽고, 다른 앱 내용은 읽지 않습니다.
- API 키는 휴대폰 안의 앱 설정에 저장됩니다.
- 요금을 낮추기 위해 가장 저렴한 모델 `claude-haiku-5-5`를 쓰고, effort는 `low`로 설정했습니다. 한 번 다듬는 데 대략 1원 안팎입니다.
- 사용량은 platform.claude.com에서 확인할 수 있습니다. 걱정되면 그곳에서 월 사용 한도를 걸어 두세요.

## 개발
- `core/Prompts.kt` — 정중하게 바꾸는 규칙(프롬프트). 말투를 바꾸고 싶으면 여기를 고칩니다.
- `core/Claude.kt` — Claude 호출 (단위 테스트: `app/src/test`)
- `KakaoAccessibilityService.kt` — 카톡 위 버튼, 카톡 화면 글 읽기, 입력창에 넣고 전송
- `HelperActivity.kt` — 말하기 → 다듬기 → 확인 → 보내기 화면
- `MainActivity.kt` — 처음 설정 화면
- 빌드: `./gradlew assembleDebug` (GitHub에 올리면 Actions가 자동으로 apk를 만듭니다)
