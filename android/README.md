# 카톡 도우미 (안드로이드)

눈이 어둡거나 자판이 불편한 분을 위한 카카오톡 도우미입니다.

- **받은 카톡을 짧게 요약해서 소리로** 들려줍니다.
- 카톡 화면 위의 **노란 '도우미' 버튼**을 누르고 **편하게 말하면**, 고른 말투로 다듬어 줍니다.
- 다듬은 문장을 **크게 보여주고 읽어준 뒤**, '보내기'를 누르면 카톡 입력창에 넣어 전송합니다.

말투는 4가지입니다: 🙏 정중하게(주임신부) · 😊 친근하게 · 🤍 위로·격려 · ✏️ 짧고 간단히

## 설치 (시험용)

1. GitHub 저장소 → **Actions** → "카톡 도우미 앱 빌드" → 맨 위 실행 → 아래 **Artifacts**의 `talk-helper-apk` 를 받습니다 (zip 안에 `app-debug.apk`).
2. 휴대폰으로 옮겨 설치합니다. "출처를 알 수 없는 앱" 설치를 허용해야 합니다.
3. 앱을 열면 나오는 순서대로 4가지를 켭니다.
   1. **카톡 알림 읽기 허용** (알림 접근)
   2. **카톡 위 도우미 버튼 켜기** (설정 → 접근성 → 설치된 앱 → 카톡 도우미)
   3. **마이크 허용**
   4. **Claude API 키 넣기** — https://platform.claude.com 에서 발급
4. 안드로이드 13 이상에서 1·2번이 회색으로 막혀 있으면: **설정 → 애플리케이션 → 카톡 도우미 → 오른쪽 위 ⋮ → '제한된 설정 허용'** 을 누른 뒤 다시 켭니다. (스토어 밖에서 설치한 앱이라 생기는 안드로이드 보안 절차입니다.)
5. 설정에서 내 이름과 "나는 어떤 사람인가요?"(예: 본당 주임신부)를 넣습니다.

## 쓰는 법

**카톡 안에서**
1. 카톡 대화방을 열면 오른쪽에 노란 **💬 도우미** 버튼이 뜹니다. 끌어서 옮길 수 있습니다.
2. 누르면 아래에서 도우미 화면이 올라옵니다.
3. **📢 카톡 요약해서 들려주기** — 이 방에서 무슨 얘기가 오갔는지 짧게 읽어줍니다.
4. 말투를 고르고 **🎤 눌러서 말하기** → 편하게 말합니다. 쉬었다 말해도 계속 듣습니다. 다 말했으면 **✅ 다 말했어요**.
   - 예: "어 그거 토요일 일곱시라고 해 저녁에. 성가 연습은 반 시간 전"
   - → 🙏 "형제님, 토요일 저녁 7시입니다. 성가 연습은 30분 전에 시작하니 참고해 주세요."
5. 다듬은 문장을 보여주고 읽어줍니다. 손으로 고칠 수도 있고, 말투를 바꾸면 다시 다듬습니다.
6. **📤 보내기** → 카톡 입력창에 넣고 전송합니다.

**앱 첫 화면에서**
- **📢 새 카톡 ○개 요약해서 듣기** — 여러 방의 새 카톡을 한꺼번에 요약해서 읽어줍니다.
- 대화방을 누르면 같은 도우미 화면이 열리고, 카톡을 열지 않고도 알림의 '답장' 기능으로 답할 수 있습니다.
- 설정에서 **새 카톡이 오면 소리로 읽어주기**를 켜면, 카톡이 올 때마다 읽어줍니다. 긴 카톡은 요약해서 읽습니다.

## 보내기가 안 될 때
카톡 앱이 업데이트되어 화면 구조가 바뀌면 자동 입력이 안 될 수 있습니다. 그때는 순서대로 이렇게 합니다.
1. 카톡 알림의 '답장' 기능으로 보냅니다.
2. 그래도 안 되면 문장을 **복사**해 두고 "입력창을 길게 눌러 붙여넣기 하세요"라고 알려줍니다.

설정에서 **전송까지 누르기**를 끄면 입력창에 넣기만 하고, 전송 버튼은 직접 누릅니다.

## 개인정보와 요금
- 받은 카톡은 이 휴대폰 안(앱 저장공간)에만 모아 둡니다. 최근 방마다 300개까지 둡니다.
- **요약**이나 **다듬기**를 할 때만 그 방의 최근 대화가 Anthropic(Claude)으로 전송됩니다. 카톡 위 버튼으로 연 경우에는 그 순간 카톡 화면에 보이던 글도 함께 전송됩니다.
- 접근성 기능은 카카오톡 화면만 읽으며, 다른 앱의 내용은 읽지 않습니다.
- API 키는 휴대폰 안의 앱 설정에 저장됩니다.
- Claude 사용료는 API 키 계정으로 청구됩니다. 모델은 `claude-opus-5-5`이고, 빠른 응답을 위해 effort를 `low`로 설정했습니다.

## 개발
- `app/src/main/java/kr/yunho/talkhelper/core/` — 말투·요약 프롬프트와 Claude 호출 (안드로이드에 의존하지 않음, 단위 테스트 있음)
- `KakaoNotificationListener.kt` — 카톡 알림 수집, 알림 '답장'으로 보내기
- `KakaoAccessibilityService.kt` — 카톡 위 버튼, 카톡 화면 글 읽기, 입력창에 넣고 전송
- `HelperActivity.kt` — 요약/말투/음성 입력/보내기 화면
- 빌드: Android Studio에서 `android/` 폴더를 열거나 `./gradlew assembleDebug`
