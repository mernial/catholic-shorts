# 카톡 대화 정리

카카오톡 "대화 내보내기" 파일을 넣으면 **누가 무슨 이야기를 했고, 내가 어떻게 답했는지**를 사람별로 정리하는 페이지입니다.
서버 없이 브라우저에서만 동작하고, 대화 파일은 어디에도 올라가지 않습니다.

## 쓰는 법
1. 카카오톡에서 대화 내보내기 (휴대폰: 채팅방 ☰ → ⚙ → 대화 내용 내보내기 / PC: ☰ → 대화 내용 → 대화 내보내기 / Mac: .csv)
2. `kakao/index.html` 페이지를 열고 파일을 끌어다 놓기 (여러 파일 한꺼번에 가능)
3. "나는" 에서 내 이름 선택 → 기간·검색어로 범위 좁히기

GitHub Pages로 배포 중이면 `https://<사이트 주소>/kakao/` 로 열립니다.
로컬에서는 이 저장소 폴더에서 `python3 -m http.server` 실행 후 http://localhost:8000/kakao/ 로 엽니다 (파일을 더블클릭해서 열면 모듈 로딩이 막힙니다).

## 화면
- **사람별 정리**: 상대가 한 말 → 나의 답 (말풍선), 답장까지 걸린 시간, 내가 먼저 꺼낸 말과 상대 반응, 아직 답하지 않은 질문, 자주 나온 말
- **시간순**: 주고받은 대화 전체를 시간 순서로
- **답 안 한 질문**: 상대가 물었는데 대화가 끊길 때까지(12시간) 답하지 않은 말
- **AI 요약** (선택): Anthropic API 키를 넣으면 Claude(`claude-opus-5-5`)가 사람별 핵심 이야기 · 부탁/질문과 나의 답 · 내가 약속한 일 · 남은 일을 정리
- 정리본을 `.md`, 표를 `.csv`(엑셀)로 저장

## 지원 형식
- 안드로이드: `2026년 10월 28일 오후 3:21, 홍길동 : 메시지`
- iOS: `2026. 10. 28. 오후 3:21, 홍길동 : 메시지`
- PC(Windows): `--- 2026년 10월 28일 수요일 ---` + `[홍길동] [오후 3:21] 메시지`
- Mac: `Date,User,Message` CSV
- 영문 설정: `Jan 5, 2024 at 3:21 PM, Name : message`

## 판단 기준
- 같은 사람이 연달아 보낸 메시지는 한 묶음으로 봅니다 (3시간 넘게 벌어지면 분리).
- 상대(들)의 말 다음에 오는 나의 말 = 그 말들에 대한 답장.
- "?", "~까요", "언제/어디/뭐", "부탁", "해주세요" 등이 있으면 질문으로 표시합니다.
- 12시간 넘게 대화가 끊길 때까지 답하지 않은 질문은 "답 안 한 질문"으로 모읍니다.

## 파일
- `kakao.js` — 파서와 분석 로직 (의존성 없음, Node에서도 import 가능)
- `app.js` — 화면
- `samples/` — 예시 대화
