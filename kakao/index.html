카톡 대화 정리

카카오톡 대화 내보내기 파일을 넣으면 누가 무슨 이야기를 했고, 내가 어떻게 답했는지 사람별로 정리합니다. 파일은 이 브라우저 안에서만 읽고, 어디에도 올리지 않습니다 (AI 요약을 직접 누를 때만 그 내용이 Anthropic API로 전송됩니다).

대화 파일(.txt / .csv)을 여기로 끌어다 놓거나

파일 내보내는 법

휴대폰: 채팅방 → 오른쪽 위 ☰ → ⚙ 채팅방 설정 → 대화 내용 내보내기 → 텍스트만 보내기 → 메일/드라이브로 저장
PC(Windows): 채팅방 → ☰ → 대화 내용 → 대화 내보내기 → .txt 저장
Mac: 채팅방 → ☰ → 대화 내보내기 → .csv 저장
여러 파일을 한꺼번에 넣으면 하나로 합쳐서 분석합니다.

Claude가 지금 선택된 기간·사람의 대화를 읽고 사람별 핵심 이야기 · 부탁/질문 · 나의 답변 · 내가 약속한 일 · 남은 일을 정리합니다.

API 키는 platform.claude.com에서 발급합니다. 키와 대화 내용은 이 브라우저에서 Anthropic API로 직접 전송되며 다른 서버를 거치지 않습니다. 개인 정보가 담긴 대화라면 전송해도 되는 범위인지 먼저 확인하세요.
