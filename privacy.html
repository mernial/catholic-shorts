개인정보처리방침 · Privacy Policy

시행일 2026년 10월 31일 · Effective October 31, 2026

Catholic Shorts(이하 “이 도구”)는 윤호요셉 신부가 자신의 YouTube 채널만을 관리하기 위해 쓰는 개인용 도구입니다. 이 도구는 YouTube API 서비스를 사용합니다. 이 도구를 사용하면 YouTube 서비스 약관에 동의하는 것이며, YouTube가 처리하는 정보에는 Google 개인정보처리방침이 적용됩니다.

1. 접근하는 정보

  • 운영자 채널의 기본 정보와 동영상 목록(제목, 길이, 조회수, 업로드 파일 이름)
  • 운영자 채널 동영상의 시청 지속 시간 통계(YouTube Analytics)
  • 운영자 채널 동영상의 자막
  • 동영상 업로드 권한(운영자가 승인한 Shorts를 운영자 채널에 올리기 위함)

다른 사람의 계정이나 시청자 개인을 식별하는 정보에는 접근하지 않습니다. 통계는 채널 전체를 합친 수치만 사용합니다.

2. 사용 목적

위 정보는 오직 운영자 채널에 올릴 Shorts를 만들고(오래 시청된 구간 찾기, 자막 넣기), 운영자가 승인한 영상을 업로드하는 데만 사용합니다. 광고, 판매, 다른 목적에는 사용하지 않습니다.

3. 저장과 보관

정보와 인증 토큰은 운영자 본인의 컴퓨터에만 저장되며, 외부 서버나 제3자에게 보내지 않습니다. 시청 지속 통계와 자막은 Shorts를 만드는 동안만 쓰고, 만든 영상과 함께 운영자 컴퓨터에 남은 기록은 최대 30일 안에 삭제합니다. API로 받은 데이터는 YouTube API 서비스 정책이 정한 기간을 넘겨 보관하지 않습니다.

4. 제3자 제공

어떤 정보도 판매하거나 제3자에게 제공하지 않습니다.

5. 권한 철회

언제든 Google 계정 보안 설정의 서드 파티 연결에서 이 도구(catholic-shorts)의 접근 권한을 끊을 수 있습니다. 권한을 끊으면 이 도구는 더 이상 채널 정보에 접근하지 못하며, 운영자 컴퓨터의 토큰도 삭제합니다.

English

Catholic Shorts (“the tool”) is a private tool used only by Fr. Yunho Joseph to manage his own YouTube channel. The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and the Google Privacy Policy applies to information processed by YouTube.

Information accessed: the owner's channel details and video list (titles, durations, view counts, uploaded file names), audience-retention analytics for the owner's videos, captions of the owner's videos, and permission to upload videos to the owner's channel. The tool does not access other users' accounts or any personally identifiable information about viewers; analytics are aggregate only.

Use: solely to create Shorts for the owner's channel (finding the most-watched moments and adding captions) and to upload Shorts the owner has approved. Never used for advertising, sale, or any other purpose.

Storage and retention: data and authorization tokens are stored only on the owner's own computer and are never sent to any external server or third party. Analytics and captions are used only while producing a Short, and any stored copies are deleted within 30 days. API data is not retained longer than permitted by the YouTube API Services policies.

Sharing: no information is sold or shared with third parties.

Revoking access: access can be revoked at any time via the Google security settings page. After revocation the tool can no longer access channel data and the stored token is deleted.
