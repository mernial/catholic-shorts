말로 답장 개인정보처리방침

시행일 2026년 11월 4일 · 운영자 윤호요셉 신부 · 문의 mernial@naver.com

「말로 답장」(직접 설치판 이름 「카톡 도우미」, 이하 “이 앱”)은 카카오와 관련이 없는 독립 앱으로, 휴대폰 자판으로 글을 쓰기 어려운 분이 말로 한 내용을 정중하거나 친근한 카카오톡 메시지로 다듬어 보내도록 돕는 앱입니다. 이 앱은 회원 가입이 없고, 운영자가 따로 운영하는 서버가 없으며, 사용자의 정보를 판매하거나 광고에 쓰지 않습니다.

1. 처리하는 정보와 목적

  • 말한 내용(음성 인식 결과 글): 사용자가 도우미 버튼을 누르고 말한 내용입니다. 음성은 휴대폰의 음성 인식 기능(예: Google 음성 인식)이 글로 바꾸며, 이 앱은 녹음 파일을 저장하거나 전송하지 않습니다.
  • 카카오톡 화면에 보이는 대화 글: 사용자가 도우미 버튼을 누른 순간 카카오톡 화면에 보이던 글입니다. 무엇에 대한 답장인지 알아서 알맞은 답장을 만들기 위해 씁니다. 접근성 권한으로 읽으며, 버튼을 누르지 않았을 때나 카카오톡 이외의 앱에서는 읽지 않습니다.
  • 다듬은 답장: 사용자가 확인한 뒤(또는 자동 전송을 켠 경우 3초 안에 취소하지 않으면) 카카오톡 입력창에 넣고 전송합니다.
  • 앱 설정: Claude API 키, 이름, 말투 설정 등은 사용자의 휴대폰 안에만 저장됩니다.

2. 제3자 제공(처리 위탁)

답장을 다듬기 위해 위 1의 말한 내용과 카카오톡 화면 글을 암호화된 연결(HTTPS)로 Anthropic, PBC의 Claude API에 전송합니다. 전송된 정보는 Anthropic의 개인정보처리방침과 상업 이용 약관에 따라 처리되며, Anthropic은 API로 받은 정보를 기본적으로 AI 모델 학습에 사용하지 않습니다. 이 앱의 운영자는 전송된 내용을 받거나 보관하지 않습니다.

3. 보관 기간

이 앱과 운영자는 대화 글이나 말한 내용을 보관하지 않습니다. 답장을 만든 뒤에는 휴대폰 메모리에서 사라집니다. 앱 설정은 사용자가 앱을 지우면 함께 삭제됩니다.

4. 권한

  • 접근성: 카카오톡 위 버튼 표시, 버튼을 누른 순간의 카카오톡 화면 글 읽기, 입력창에 글 넣기와 전송 버튼 누르기에만 씁니다.
  • 마이크: 말로 답장하기 위한 음성 인식에만 씁니다.
  • 인터넷: Claude API 호출에 씁니다.

5. 이용자의 권리

사용자는 언제든 휴대폰 설정에서 접근성·마이크 권한을 끄거나 앱을 삭제해 정보 처리를 멈출 수 있습니다. 문의는 위 이메일로 보내 주세요.

6. 아동

이 앱은 만 14세 미만 아동을 대상으로 하지 않습니다.

7. 변경

이 방침이 바뀌면 이 페이지에 시행일과 함께 알립니다.
