말로 답장 개인정보처리방침

시행일 2026년 11월 6일 · 운영자 윤호요셉 신부 · 문의 mernial@naver.com

「말로 답장」(직접 설치판 이름 「카톡 도우미」, 이하 “이 앱”)은 카카오와 관련이 없는 독립 앱으로, 휴대폰 자판으로 글을 쓰기 어려운 분이 말로 한 내용을 정중하거나 친근한 카카오톡 메시지로 다듬어 보내도록 돕는 앱입니다. 이 앱은 회원 가입이 없고, 운영자가 따로 운영하는 서버가 없으며, 사용자의 정보를 판매하거나 광고에 쓰지 않습니다.

1. 처리하는 정보와 목적

  • 말한 내용(음성 인식 결과 글): 사용자가 도우미 버튼을 누르고 말한 내용입니다. 음성은 휴대폰의 음성 인식 기능(예: Google 음성 인식)이 글로 바꾸며, 이 앱은 녹음 파일을 저장하거나 전송하지 않습니다.
  • 카카오톡 화면에 보이는 대화 글: 사용자가 도우미 버튼을 누른 순간(답장 또는 찾기) 카카오톡 화면에 보이던 글입니다. 무엇에 대한 답장인지, 무엇을 찾는지 알기 위해 씁니다. 답장을 다듬을 때는 화면 글 가운데 가장 최근 부분(최대 1,200자)만 보냅니다. 접근성 권한으로 읽으며, 버튼을 누르지 않았을 때나 카카오톡 이외의 앱에서는 읽지 않습니다.
  • 다듬은 답장: 사용자가 확인한 뒤(또는 자동 전송을 켠 경우 3초 안에 취소하지 않으면) 카카오톡 입력창에 넣고 전송합니다.
  • 대화에서 찾기: 사용자가 카카오톡 '대화 내용 내보내기'로 이 앱에 직접 공유한 대화는 휴대폰 안(앱 저장공간)에만 저장되며, 사용자가 질문할 때 질문과 관련된 부분만 골라 답을 찾기 위해 Anthropic의 Claude API로 전송됩니다. 대화와 함께 내보낸 사진은 휴대폰 안에만 저장되고 외부로 전송되지 않으며, 사진을 찾을 때는 대화 글로 찾은 시각에 맞춰 휴대폰 안에서 골라 보여 줍니다. 저장된 대화와 사진은 앱의 '이 대화 지우기'나 앱 삭제로 지울 수 있습니다.
  • 내 말투: '내 말투'로 다듬을 때, 사용자가 이 앱에 저장한 그 대화방에서 사용자가 직접 보낸 최근 메시지(최대 30개, 사진·링크 제외)를 말투 예시로 함께 Anthropic의 Claude API로 전송합니다. 고르는 일은 휴대폰 안에서 하며, 다른 사람이 보낸 메시지는 예시로 보내지 않습니다.
  • 앱 설정: Claude API 키, 이름, 말투 설정 등은 사용자의 휴대폰 안에만 저장됩니다.
  • 사용 기록: 이번 달 답장·찾기 횟수와 사용량, 보내기·대화 내보내기가 잘 됐는지의 기록(문제 해결용)은 휴대폰 안에만 저장되며 외부로 전송되지 않습니다.
  • 이상한 답장 알리기(🚩): 사용자가 이 버튼을 누르고 '알리기'를 고른 경우에만, 사용자가 적은 설명, 그때 말한 내용, AI가 만든 글, 앱 버전이 운영자의 Google 설문지(Google Forms)로 전송됩니다(사용자가 원하면 메일로도 보낼 수 있습니다). 이름·전화번호·계정 같은 식별 정보는 보내지 않습니다. 운영자는 이를 문제 확인과 앱 개선에만 쓰고, 처리를 마치면 지웁니다. 앱이 몰래 보내는 일은 없습니다.

2. 처리 위탁

답장을 다듬거나 대화에서 답을 찾기 위해 위 1의 말한 내용, 카카오톡 화면 글, 질문과 관련된 대화 부분을 암호화된 연결(HTTPS)로 Anthropic, PBC의 Claude API에 전송합니다. 전송된 정보는 Anthropic의 개인정보처리방침과 상업 이용 약관에 따라 처리되며, Anthropic은 API로 받은 정보를 기본적으로 AI 모델 학습에 사용하지 않습니다. 이 앱의 운영자는 전송된 내용을 받거나 보관하지 않습니다.

3. 개인정보의 국외 이전

「개인정보 보호법」 제28조의8에 따라, 이 앱의 기능을 쓰는 데 꼭 필요한 범위에서 아래와 같이 개인정보가 국외로 이전됩니다. 이 앱의 핵심 기능(말한 내용을 다듬어 보내기, 대화에서 찾기)이 이전 없이는 동작하지 않으므로, 이전을 원하지 않으시면 이 앱을 쓰지 않거나 지우시면 됩니다.

4. 보관 기간

이 앱과 운영자는 대화 글이나 말한 내용을 보관하지 않습니다(사용자가 직접 공유해 저장한 '대화에서 찾기'용 대화와 사용 기록은 휴대폰 안에만 있으며 사용자가 지울 수 있습니다. 사용자가 🚩로 보낸 알림은 처리 후 지웁니다). 답장을 만든 뒤에는 휴대폰 메모리에서 사라집니다. 앱 설정은 사용자가 앱을 지우면 함께 삭제됩니다.

5. 권한

  • 접근성: 카카오톡 위 버튼 표시, 버튼을 누른 순간의 카카오톡 화면 글 읽기, 입력창에 글 넣기와 전송 버튼 누르기에만 씁니다.
  • 마이크: 말로 답장하기 위한 음성 인식에만 씁니다.
  • 인터넷: Claude API 호출에 씁니다.

6. 이용자의 권리

사용자는 언제든 휴대폰 설정에서 접근성·마이크 권한을 끄거나 앱을 삭제해 정보 처리를 멈출 수 있습니다. 앱의 자세한 설정(앱 제목을 길게 누르기)에 있는 '저장한 대화·기록 모두 지우기'로 휴대폰에 저장된 대화·사진·기록을 한 번에 지울 수 있습니다. 문의는 위 이메일로 보내 주세요.

7. 아동

이 앱은 만 14세 미만 아동을 대상으로 하지 않습니다.

8. 변경
